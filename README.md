# FetchData (React + Vite)

A small React demo app that fetches posts and users from JSONPlaceholder. It demonstrates basic CRUD interactions (fetch, create, update, delete) and a simple UI to browse posts and users.

## Features

- List posts and users (fetched from JSONPlaceholder)
- Search posts by title/body
- Create new posts and users (POST to JSONPlaceholder)
- Edit and delete posts
- Responsive, minimal UI

## Requirements

- Node.js 16+ (or a recent LTS)
- npm (bundled with Node.js)

## Quick start

1. Install dependencies

```powershell
npm install
```

2. Run the dev server

```powershell
npm run dev
```

3. Open the app

- Visit the address shown by Vite in the terminal (usually `http://localhost:5173`).

## Scripts

- `npm run dev` — Start Vite dev server
- `npm run build` — Build production assets
- `npm run preview` — Preview the production build locally

## Notes

- This project uses the public JSONPlaceholder API (https://jsonplaceholder.typicode.com). The API accepts POST/PUT/DELETE calls but doesn't persist changes permanently.
